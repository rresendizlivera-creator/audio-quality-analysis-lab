# Audio Quality Analysis Lab 🎧

**Offline PCM WAV diagnostics with JSON output and a standalone HTML report.**

This independent Python project demonstrates reproducible technical checks for audio recordings. It uses only the standard library and runs locally: no account, API key, server, or upload is required.

[Quick start](#quick-start) · [Example report](examples/demo-report.html) · [Tests](tests/test_audio_quality.py) · [Scope and limits](#scope-and-limits)

## What it measures

- Format, sample rate, channels, bit depth, and duration for uncompressed 8/16/24/32-bit PCM WAV.
- Peak and RMS levels, near-full-scale samples, near-silent samples, and DC offset.
- Longest continuous near-silent interval and per-channel RMS.
- A 20 ms frame-peak waveform overview and threshold-based review flags.

The JSON file retains frame peaks for further analysis. The HTML report is self-contained and responsive, so it can be opened locally in a desktop or mobile browser.

## Quick start

**Requirement:** Python 3.10 or newer. No package installation is needed.

From the repository root, generate the original synthetic sample and analyze it:

```bash
python examples/create_demo_audio.py
python audio_quality.py examples/demo.wav --json examples/demo-report.json --html examples/demo-report.html
```

Open `examples/demo-report.html` in a browser. The repository also includes the pre-generated [example JSON](examples/demo-report.json) and [HTML report](examples/demo-report.html).

Analyze your own uncompressed PCM WAV file:

```bash
python audio_quality.py path/to/recording.wav --json result.json --html report.html
```

The command prints a summary to the terminal. The `--json` and `--html` options are optional. Use a recording you own or have permission to analyze. Convert other formats to PCM WAV locally before running the tool.

Run the tests:

```bash
python -m unittest discover -s tests -v
```

## Reading the results

| Metric | Interpretation |
| --- | --- |
| Peak dBFS | Highest absolute sample magnitude. |
| RMS dBFS | Overall signal energy; not a speech loudness standard. |
| Near-clipping | Percentage of samples at or above 0.998 absolute amplitude. |
| Longest near-silence | Longest sequence of 20 ms frames below −50 dBFS RMS. |
| DC offset | Mean signed sample amplitude. |
| Channel RMS | Energy by channel; a stereo difference over about 6 dB is flagged. |

The supplied demo intentionally includes a saturated interval and DC offset so the report shows review flags. Flags are prompts to listen and investigate, not automatic pass/fail grades.

## Scope and limits

This tool does **not** judge pronunciation, naturalness, speaker identity, accent, intelligibility, or preference. Thresholds are simple heuristics and should be adapted to the recording context. It reads uncompressed PCM WAV only; it does not decode MP3, AAC, or other compressed formats.

All example audio is synthetic and generated by [source code](examples/create_demo_audio.py). No private recordings, client assets, proprietary guidelines, or confidential platform materials are included. This personal portfolio project is not affiliated with any evaluation platform.
